# BGA 农家乐记牌器

Board Game Arena（BGA）农家乐（Agricola）的 Chrome 扩展。在牌桌上显示一个浮动面板，帮你记住轮抽（draft）时看过、传出去的牌，并推理这些牌现在在谁手上。主要针对**竞技场**（4 人，9 张选 7，职业卡和小发明卡一起轮抽）。

> 目前是试用版。轮抽推理用真实的 4 人竞技场对局回放验证过，但实战测试还不多，遇到问题欢迎回报。

## 面板内容

| 区块 | 说明 |
|---|---|
| **被拿走** | 你传出的牌堆传回来时少掉的牌，一定被别人拿走了。面板会列出可能是谁拿的，只剩一个人时显示「确定：某某」 |
| **去向未明** | 你传出、还没传回来的牌：列出可能拿到它的玩家，或标示已被弃掉 |
| **已打出** | 每位玩家打出的职业卡和小发明卡。绿框表示你在轮抽时看过这张牌 |
| **我的牌** | 你在轮抽中拿到的牌 |

推理依据：

- **传牌方向**：会自动判断。
- **候选范围**：根据剩下的轮数，算出这张牌还可能被哪几位玩家拿到。
- **排除推理**：每人每轮每种牌只拿 1 张。所以有人打出同一叠牌里的另一张同类型卡后，他就会被排除。

面板标题栏的按钮：简/繁 切换简体或繁体、↻ 重新读取牌桌、⤓ 导出记录（JSON）、✕ 清除本桌记录、▾ 收起。面板可以拖动。

记录按牌桌分别保存在你自己的浏览器里，刷新页面不会丢失。

## 安装方法

需要使用 **Chrome** 或 **Edge** 浏览器（电脑版）。

1. 下载：点这个页面上方绿色的 **Code** 按钮，选 **Download ZIP**，然后解压缩到一个固定的文件夹。之后别删掉或搬走这个文件夹，扩展会直接从这里读取文件。
2. 打开扩展管理页：Chrome 在地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 打开右上角（Edge 在左下角）的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择刚才解压出来、里面有 `manifest.json` 的那个文件夹。
5. 进入 BGA 的农家乐牌桌（已经开着的话请刷新页面），左上方就会出现「🌾 记牌器」面板。

**更新方法**：下载新版 ZIP，覆盖原来的文件夹，再到扩展管理页点这个扩展的刷新按钮。

## 注意事项

- **一定要在轮抽开始前装好**。BGA 不会重发轮抽记录，装好之前的轮抽无法补记。
- 观战时看不到轮抽和手牌，初学者模式没有职业卡和小发明卡，这两种情况面板都没什么内容。
- 面板会跟随浏览器语言，自动显示简体或繁体；也可以点标题栏的「简/繁」切换，选择会被记住。卡牌名称则跟随你 BGA 的语言设置。
- 这个扩展只读取你自己浏览器里的游戏画面数据，不会上传任何东西，也不会替你操作游戏。

## 技術細節

### 運作方式

| 檔案 | 執行環境 | 職責 |
|---|---|---|
| `src/inject.js` | 頁面 MAIN world，所有 frame | 等 `window.gameui` 載入，讀取 `gamedatas` 送出快照，並包一層 `gameui.notifqueue.dispatchNotification` 來轉送追蹤的通知 |
| `src/content.js` | isolated world，所有 frame | 處理記牌狀態、存檔，以及用 shadow DOM 畫面板 |
| `src/background.js` | service worker | 開發用：以「載入未封裝項目」安裝時，偵測檔案變動後自動重新載入 extension，並重整 BGA 牌桌分頁 |

正在進行的牌桌（`/tableview?table=N`）裡，遊戲跑在 `iframe#gameIframe`，所以兩支腳本都設了 `all_frames`。

用到的通知：`newDraftPile`、`add/remove/confirmDraftSelection`、`draftWaiting`、`draftProgress`、`clearDraftPools`、`draftIsOver`、`refreshHand`、`buyCard`、`buyAndPassCard`、`buyAndDestroyCard`。打出卡的人以 `args.player_id` 為準，因為 `buyAndPassCard` 的 `card.pId` 是傳出後的狀態。

### 輪抽推論

- 傳牌方向：從 `draftWaiting.predecessorId`（傳牌給我的人）判斷。在實際的 4 人局裡，整場輪抽方向固定，都是傳給 `playerorder` 的下一位。
- 候選範圍：我在第 t 輪傳出的牌，只可能被下家 1…k 拿走，其中 k = min(玩家數 − 1, 總輪數 − t)。如果這疊牌傳回來時少了某張，就一定被拿走了；沒傳回來的則也可能被棄。
- 排除推論：每輪每人每種牌只拿 1 張。如果某位玩家打出了同一疊牌裡另一張同類型的牌，他就被排除。

### 驗證

- 用一場真實 4 人局的重播（重播裡包含所有玩家的私人輪抽頻道）做回放：只把我自己頻道收到的通知餵給 content.js，再拿全部玩家的選牌紀錄當正確答案比對，所有判斷都正確。
- 同一場重播也確認：新的一疊牌一定在我確認選牌之後才送達。

### 除錯

- 遊戲 iframe 的 DevTools console 裡，`window.__agrRecLog` 保留了所有追蹤到的原始通知。
- `livingHand*` 這類輪抽方式目前只會記下卡牌名稱，不會納入記牌邏輯。
